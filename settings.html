正确的 JSON 示例（普通模式）假设选中原文 id 是 m0p0，原句为“她坐在窗边看书。”。实际 id 和句子必须使用你捕捉到的内容；多图在 scenes 中放多个对象，不要返回多个独立 JSON。
{
  "scenes": [{
    "title": "窗边阅读",
    "prompt": "1girl, sitting by a window, reading a book, soft daylight",
    "negative_prompt": "blurry, low quality",
    "source_ids": ["m0p0"],
    "anchor_source_id": "m0p0",
    "anchor_quote": "她坐在窗边看书。",
    "anchor_occurrence": 1
  }]
}
开启多角色模式时，每个对象还需 characters 数组，角色字段为 name、prompt、negative_prompt、x、y。关闭时不用加。

生成 tags 的预设

支持 TXT、prompt/system_prompt/messages JSON，以及酒馆 prompts/prompt_order。仅导入文本指令，不执行脚本；预设会与勾选原文一起发送给副 API。

全局美化

美化文件是 JSON：{"name":"名字","css":"CSS 内容"}，也可以直接导入 .css 文件。CSS 只改外观，会盖在默认样式上面；想改哪里可以先点“填入选择器示例”看常用的名字。

悬浮按钮与入口

默认图片已随扩展附带，无需图床；自定义链接会向该图片地址发起请求。

官网高级参数

两种方式都请求 NovelAI 官方。自动模式下，基础参数复用酒馆转发；Rescale、Variety、角色提示及高级 JSON 自动直连官方，发送完整参数。直连可记住本浏览器的 Token，刷新后自动复用。其他扩展可以采用自己的转发方式，不受这里的接口限制。一般留空即可；V5 已在模型列表里（nai-diffusion-5-full / curated）。只有官网出了列表里没有的新模型时才需要填。
官网直连可传递 cfg_rescale、v4_prompt / v4_negative_prompt 的角色提示、reference_*、director_reference_* 等官方 parameters；填写结构必须匹配模型。固定正负面仍作为 base_caption，始终一次一张。直连需要本浏览器保存的 Token，可能受浏览器跨域限制。图生图、局部重绘、氛围、精确参考等在星绘页「官网功能」里设置。

聊天界面恢复

重新加载当前聊天，不刷新网页。自动模式在停止操作 30 秒后恢复一次，至少间隔 2 分钟；生成、猫猫任务、消息编辑、输入草稿或弹窗期间暂停。正常界面也可能重载，嵌入界面的临时状态可能丢失；其他插件的后台任务不一定能识别。重载会触发原有聊天加载脚本。已安装独立恢复版时，请先停用独立版并刷新。
