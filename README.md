# ฅ Meow · 猫猫星绘

粉白、猫猫、星星风格的 SillyTavern NovelAI 文生图扩展。基础版 0.2.0，无需构建、无需 Extras 或额外服务器插件。

## 安装

要求 **SillyTavern 1.19.0 或更新版本**（按当前官方 release 源码实现）。打开酒馆 → 扩展 → 安装扩展，粘贴：

```text
https://github.com/Lumi729/meow
```

安装后刷新页面，点击右侧猫猫悬浮按钮，或聊天输入栏魔法棒里的 **Meow · 猫猫星绘**，打开独立面板。悬浮按钮支持拖动并记住位置；关闭面板不会清空提示词或当前图片。扩展设置保留一个备用打开按钮。更新时在酒馆扩展管理中更新本扩展，再刷新页面。

## 配置与生图

1. 在 NovelAI 官方账号设置中取得 **Persistent API Token**。不要把 Token 发给别人或提交到 GitHub。
2. 在「连接 NovelAI」中粘贴 Token，点击「保存本地 Token」。已在酒馆配置 NovelAI 密钥时可直接复用。
3. 填写画面描述，例如 `a fluffy white cat, pink bow, twinkling stars, pastel colors`，选择 V4.5 Full 或 Curated。
4. 点击「猫猫，开始画画」，等图片出现后点击「保存 PNG」。

默认 832×1216、28 步、引导 5，每次一张。宽高须为 64 的倍数，总像素不超过 1,048,576；最多 28 步。种子 -1 表示随机，结果下显示实际种子，可填回重用。固定 Euler Ancestral / Karras，无额外质量词、放大或自动重试。

**生成可能消耗 Anlas，尺寸限制不保证免费。** 图片只保留在当前页面预览，刷新会丢失，务必下载。本版不自动发到聊天，不自动批量生图。

## Token 与隐私

Token 由用户在自己的酒馆里输入，调用酒馆自带密钥管理保存到该酒馆服务器（云端托管酒馆则是该服务器，不是浏览器设备）。与原生 NovelAI 连接共用密钥；保存会更改当前使用的 NovelAI 密钥，可在酒馆密钥管理里切换或删除。本扩展不将 Token 写入 extensionSettings、localStorage、聊天、图片文件或仓库，不回显已存 Token，保存尝试后清空输入框。不保证酒馆密钥文件在磁盘上加密。

浏览器只向同源酒馆发送请求；酒馆向 NovelAI 官方图像接口转发提示词和参数并附加 Token。扩展不使用第三方代理、远程脚本、字体、统计或 CDN。

## 故障排查

- 没有面板：检查酒馆版本、扩展是否启用，再刷新页面。
- 未配置 Token：展开连接设置保存密钥；「已配置」仅代表有密钥，不证明密钥有效。
- HTTP 404：更新酒馆；扩展依赖原生 `/api/novelai/generate-image`。
- HTTP 500：酒馆可能把 NovelAI 的 Token、余额、限流等错误统一返回 500。检查服务器日志与 NovelAI 余额，不要反复点击。
- 超时：等待上限 180 秒；浏览器中止等待不保证上游停止，仍可能计费。确认日志后再手动重试。
- 原生 NovelAI 的订阅状态检查报错时，不代表图像接口一定不可用；本扩展不依赖该旧状态检查。

## 验证

`npm test` 运行无依赖单元测试。官方接口与源码依据见 [docs/API.md](docs/API.md)。浏览器模拟验证不能代替真实 NovelAI 生图；维护者未持有用户 Token，未进行付费端到端调用。安装后由用户本地完成首次真实生图。
