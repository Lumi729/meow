# ฅ Meow · 猫猫星绘 0.3.0

给 SillyTavern 的粉白猫猫 NovelAI 文生图扩展：独立面板、配置预设、持久图库、坏猫猫图文流程。无需构建，无需额外服务器插件。建议 SillyTavern 1.19.0+。

## 安装与更新

酒馆 → 扩展 → 安装扩展，粘贴 `https://github.com/Lumi729/meow`。已有版本点击扩展更新，完成后刷新页面。打开入口：魔法棒菜单、顶栏 ✦、右侧悬浮图片，扩展设置也有备用入口。

普通模式悬浮图片是唱片机，坏猫猫模式是「爱」。设置里可以关闭悬浮、调节 36–120px 大小、填写 HTTPS 图片链接或恢复默认位置。拖动图片移动位置；尺寸变化时会重新限制到屏幕内。

## 星绘与配置

设置页填写 NovelAI Persistent API Token 并保存。旧版本已保存的 Token、提示词和参数继续使用。

- 固定正面 + 本次描述合并为正面提示；固定负面 + 本次补充负面合并为负面提示。
- 常用参数提供独立控件：模型、尺寸、采样器、噪声计划、步数、引导、种子、Decrisper、Variety Boost、SMEA / DYN、放大。
- 已核对模型：V4.5 Full/Curated、V4 Full/Curated、Anime V3、Furry V3、Anime V2。
- 配置可以命名保存、切换、删除、导入和导出 JSON。包含绘图参数、固定提示词和高级 parameters，不包含 Token 或副 API 密钥。
- 默认节省模式限制 28 步、1MP 和不放大；关闭后可设置至 50 步、2048×2048。该限制是扩展的产品限制，不是官方完整配额。所有生成和放大都可能消耗 Anlas，不保证免费。

## 图库

生成后自动存入当前浏览器的 IndexedDB，按酒馆用户的独立标识隔离。可以筛选全部 / 当前聊天 / 坏猫猫图文。点击缩略图打开大图，点图片放大，左右滑动或上一张/下一张切换；支持下载、删除和以新种子重绘。重绘保留旧图，复用当时的参数和原文。

坏猫猫图片附有所引用原文、实际正负提示词、种子和模型。可手动插入当前来源聊天；删除图库记录不会删除已经插入聊天的副本。图库数据仅在这个浏览器里，清除网站数据会丢失，也不会自动同步到其他设备。存储失败时会提示立即下载。

## 坏猫猫：把当前故事画出来

1. 设置副 API 基础地址（例如 `https://服务商/v1`）、模型、密钥；仅支持 OpenAI 兼容 Chat Completions。
2. 导入或编辑生成 tags 的预设。支持 TXT、`system_prompt` / `prompt` / `messages` JSON，以及酒馆 `prompts` / `prompt_order`。只读取启用的文本，不执行脚本、宏、世界书或其他酒馆预设功能。
3. 在坏猫猫页设置最近 1–50 条消息、生成 1–8 张图片。
4. 按原文实际格式设置分区标记：默认 `<正文>…</正文>`、`<小剧场>…</小剧场>`、`<状态栏>…</状态栏>`。规则是字面起止字符串，不是正则。嵌套标签以外层分区为准。不匹配的内容显示“未分类原文”，默认不发送。
5. 点击捕捉，逐段勾选正文 / 小剧场 / 状态栏或未分类原文。文本框还可手动删改；最终发送预览和目标 API 明确显示。捕捉不会发请求。
6. 点击“只发送勾选内容，生成 tags”，把预设和选中原文发给副 API。返回必须包含恰好指定数量的 scenes 和有效 source_ids；格式不合格时不会自动生图，原始返回可查看。
7. 编辑返回 tags 后点击“用这些 tags 生成图片”。每张 tags 加上星绘页固定正负面，顺序生成。普通星绘的本次正面描述不会混进坏猫猫 tags。
8. 默认放入带原文的图文相册；也可选择同时作为新消息插入当前聊天。不会改写原有正文。切换聊天后需重新捕捉，防止发错原文或插错聊天。

副 API 请求上限 120 秒，NovelAI 请求上限 180 秒，无自动重试。可以停止后续任务；已经发出的请求可能仍生成并计费。失败前完成的图片会保留。

## 官网高级参数与边界

酒馆内置通道只转发有限参数；不能把未转发的参数做成假开关。因此保留稳定的酒馆通道，另提供固定目标 `https://image.novelai.net/ai/generate-image` 的官网直连（`Accept: application/json`）。直连使用当前页面内存中的 Token，需要刷新后重新填写，不能回读服务器密钥。

高级直连可填写完整 `parameters` JSON 或导入官方 generate 请求，包括 cfg_rescale、角色 v4_prompt / v4_negative_prompt、reference_* 与 director_reference_* 参数。提供一个 V4 角色提示的结构示例。主控件里的宽高、步数、引导、种子、采样器、噪声计划为准；固定正负面始终合并到 base_caption；每次一张。直连请关闭酒馆放大与 Variety Boost，使用官网对应参数。

**尚未做到官网全部交互界面。** Vibe / Precise Reference 的编码和上传编辑器、官网画布、局部重绘、Director Tools 暂未实现；不能将这里称为完整官网克隆。官方文档现在列有 V5，但机器 schema 不枚举模型标识，已核对的酒馆源码尚未提供 V5 标识，因此不猜测预填。支持手动填写从官方请求确认的模型 API 标识。

官网直连可能受浏览器 CORS 或网络策略限制，未进行真实 Token 调用；遇到跨域问题可切回酒馆通道。不会绕过浏览器保护或启用公共代理。

## 密钥与隐私

NovelAI Token 存到当前酒馆服务器的原生密钥管理。副 API 使用酒馆 Custom 密钥管理并绑定具体 ID；保存时也会更新酒馆 Custom 当前密钥，已有密钥保留在密钥管理中可切换。地址、模型、预设、密钥 ID 可以在设置中保存，密钥值不进扩展设置、导出、图库或仓库。官网直连额外在当前页面闭包中保留用户刚输入的 Token，刷新后释放。

坏猫猫只发送勾选文本与 tags 预设，不自动发送角色卡、世界书、未选状态栏或系统消息。图片数据和原文只保存在用户端 / 用户酒馆中，不上传 GitHub。自定义悬浮图片链接会访问对应地址，默认素材随仓库附带。图库包含原文，请按聊天隐私对待。

## 验证与开发

`npm ci && npm test && npm run test:ui`。依赖仅用于开发测试，酒馆安装无需 npm。

单元测试覆盖参数、上下文分区、原文选择、预设白名单、返回引用校验、官方 JSON 返回、错误和中止。DOM 集成测试用模拟 API 验证入口、配置、坏猫猫流程、图库保存与删除、来源对应、切换聊天拦截。未使用真实密钥验证上游生图；手机实际布局需在用户酒馆验收。详细接口依据见 [docs/API.md](docs/API.md)。

坏猫猫勾选「生成多角色 tags 和位置」，会把 characters 格式要求追加到现有预设。使用 V4/V4.5 和官网直连（本次页面保存 Token），返回后逐人编辑正负 tags、0–1 的 x/y 位置，再生成。最多 6 人是本扩展限制；场景和固定正负面合并为 base_caption，角色正负面按相同顺序发送。角色编辑只覆盖本幅的角色参数，不覆盖全局高级 JSON。图库保存实际请求，重绘沿用角色数据。普通模式仍兼容旧预设。未做真实付费调用。
